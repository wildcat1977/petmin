狗狗帶路，找回消失的垃圾桶

遛狗族每天走同一條路，是最穩定的巡桶人。這份是我（Summer）整理的理想版使用流程：手上有便便時找得到桶、太遠時讓「這裡需要桶」被看見，路過時碰一下就能回報，再用扭蛋收集卡片，讓大家願意天天順手做。

程式在 sun40421/petmin fork 的 feature/find-bin 分支 準備發 PR 回 main LINE 官方帳號 @358xpblo（LINE Login 與 Messaging API 頻道已建立）

兩段目標，一套系統

Petmin 原本的分析平台負責第一段；這次新增的功能把市民接進來，資料再回流到同一個需求分數。

① 讓市府知道哪裡該復設垃圾桶
  • 我找垃圾桶：最近 3 個清潔箱，依步行距離排序，一鍵導航
  • 好遠！：太遠就按，匿名留下「這附近需要桶」
  • 需求熱力、候選設桶點、行政區排行、匯出（Petmin 原有）
② 讓管理滿溢變輕鬆
  • 巡桶打卡：碰 NFC 貼紙或掃 QR，直接回報這個桶
  • 扭蛋劇情：回報完抽一段小劇情，收進狗狗圖鑑
  • 回報、照片審核、點數、英雄榜（Petmin 原有）

一條完整的遛狗日常

兩個入口：有需要時主動找桶，或路過時碰一下貼紙。兩條路最後都回到 Petmin 的需求分數與後台審核。

入口一：我找垃圾桶＋好遠！

網址 /find，不用登入。以下是本機實測的手機畫面（示範位置：中正區）。

/find
  1. 定位或用示範位置。定位失敗不會偷偷改用預設座標，避免把地圖中心記成需求。
  2. 列出最近 3 個行人清潔箱（排除狗便袋箱和已消失的桶），依步行距離排序，附幾分鐘。
  3. 帶我去：開 Google 地圖步行導航，不需要金鑰。
  4. 覺得太遠就按好遠！。同一個 IP、同一格（150 公尺）、同一天只算一次；位置只存格中心。

步行距離怎麼算：用開源步行路網（OSRM，免金鑰）。實測中正區一組座標，直線 380 公尺、實際步行 761 公尺。路網掛了就改用直線 × 1.3 估算並標「約」，展示時不會整個壞掉。
「好遠！」進需求分數：權重是「這裡需要桶」回報的一半，每格另有上限，匿名訊號淹不掉其他證據。

入口二：碰一下貼紙就打卡

每個桶一個專屬網址 /b/官方編號，NFC 貼紙和 QR Code 都指向它。回報表單直接沿用 Petmin 原本的，桶和位置自動帶入。

/b/clean_box_area-…
  1. 手機碰貼紙或掃 QR，看到「打卡成功」蓋章和這個桶的資訊（幾天前有人確認還在）。
  2. 按回報這個桶的狀況，沒登入會跳出原本的登入引導（之後走 LINE）。
  3. 拍照、選滿了／壞了／有異味／正常，送出後進後台審核。
  4. 審核通過加點，並播一段扭蛋劇情（見下一段）。

為什麼網址用官方編號：資料庫自動編號在每個環境都不一樣，貼紙寫死號碼，換到正式站就會指錯桶。官方編號來自環保局資料，各環境一致。
實體提醒：市府的桶要環保局同意才能貼；台北清潔箱多是金屬外殼，要用抗金屬貼紙。展示時用道具桶，QR 當主要方案、NFC 當現場亮點。

隨機的扭蛋劇情，收集不一樣的卡片

每次回報通過後隨機播一段小劇情，最後抽到一張卡，收進狗狗圖鑑、可以分享，集越多越想再去巡桶。我們先做了兩種劇情的 demo；動畫目前是粗糙版，接下來會再改細節，讓它更好笑、更好玩。

劇情一：金銀垃圾桶

水溝蓋冒出垃圾桶神，問要金的、銀的還是普通的垃圾桶。主人提著便便袋左看右看，狗狗好緊張。主人說：「都可以，我只想丟屎。」神說：「你真是個誠實的人，三種都給你吧！」收集到卡片「誠實的丟屎人」。

劇情二：抽鬼牌

第一人稱牌局：主人手上是 20%、40%、120% 滿的垃圾桶。手晃到哪張，對面的狗狗表情就跟著變。抽中間那張，翻開是超級乾淨的垃圾桶，狗狗戴上皇冠：「汪！我是垃圾桶富翁！」收集到卡片「超級乾淨的垃圾桶」。

需要一起確認的事

wildcat 的 AI 評估給了很多好建議，防灌票、待驗證標籤、QR 為主 NFC 為輔都已經照改。以下幾點想跟 wildcat 對齊：

PR 合併與部署

分支準備好就從 fork 發 PR 回 main。新增資料表 far_signals 和需求分數權重，部署後需要跑 migrate 和一次 demand:recompute。

LINE 金鑰交接

我已建立 LINE Login 頻道（ID 2012143486）與 Messaging API 頻道；頻道密鑰會另外用安全的方式給，不會貼在聊天裡。LIFF 的入口網址設成 https://petmin.wildcat.tw，建好後再把 LIFF ID 交給 wildcat 填進正式機。

後台新增兩個回報分類

「壞了」「有異味」想直接在正式站後台新增，請 wildcat 確認 slug 和顯示順序有沒有偏好。

打卡頁的「使用前請注意」

第一次碰貼紙會先跳進站聲明，才看到打卡蓋章。想討論打卡頁能不能改成蓋章後才提醒，或維持現狀。

照片必填的範圍

想只在「打卡進來的回報」必填照片，一般回報維持選填，不動原本的產品邏輯。這樣可以嗎？
