# Demo 腳本（5 分鐘）

0. **開場（30s）**：台北 2,000 → 806 組垃圾桶。環保局只知道「哪裡被亂丟」，不知道「哪裡需要」。我們補那一半。
1. **有袋沒桶（60s）**：開 `/candidates`，指 98 / 124。切到地圖 🧷 圖層，點一個袋箱：「最近清潔箱 300m 內沒有」。
   > 台詞：環保局自己的兩份 open data 一 join 就看得到的痛點，但沒有人 join 過。
2. **回報（90s）**：手機 LINE 打開 → 自動登入 → 點地圖上一個桶 →「回報這個桶」→ 選「桶滿了 80%」→ 拍照 → 送出。
   地圖立刻多一個點。第二支手機再回報同一桶 → 升級「多方佐證」。
3. **找回（45s）**：切 👻 圖層，示範一個「桶消失了」核准後桶變紫色幽靈。
4. **決策（60s）**：回 `/candidates`，展開第一名：證據明細（捷運站、幾個站牌、幾筆回報、扣掉幾個現存桶）。按匯出 CSV：「這張表可以直接附在環保局的評估表後面送會勘」。
5. **遊戲化 + 落地（30s）**：巡桶英雄榜、點數換專用垃圾袋。零硬體先跑 3 個月 → 挑 20 點復設 → 裝感測器驗證 → 全市。

備援：現場網路不穩時，所有 open data 都在 repo 內，`php artisan migrate:fresh --seed` 30 秒重建全部資料。
