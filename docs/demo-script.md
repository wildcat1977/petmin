# Demo 腳本（5 分鐘）

各功能的細節、限制與被問到時的回答在 [demo-features.md](demo-features.md)。數字以當天 `/candidates` 頁面為準（每天 04:00 同步）。

**事前準備**：兩支手機各登入不同帳號（至少一支從 LINE 選單打開）；一張巡桶貼紙（後台 `/print/bin-stickers` 印），貼在會場附近、或拿在手上示範；筆電開好 `/candidates` 和首頁地圖。

---

0. **開場（30s）**：台北的行人清潔箱從約 2,000 組裁到 806 組。環保局撤桶時只看得到「哪裡被亂丟」，看不到「哪裡需要」。我們補那一半。

1. **有袋沒桶（45s）**：筆電開 `/candidates`，指頁首統計卡：468 個狗便袋箱，57% 在 100 公尺內沒有清潔箱；中正區每個袋箱分到 8.9 組清潔箱，南港只有 0.6，差將近 15 倍。
   切到地圖打開 🧷「有袋沒桶」圖層，點一個袋箱：「最近清潔箱 300m 內沒有」。
   > 台詞：環保局自己的兩份 open data，一對照就看得到這個痛點，只是沒有人對照過。

2. **遛狗族的一天（120s，手機投影）**
   - **找桶**：LINE 選單「我找垃圾桶」（會場定位不準就按「用示範位置」），列出最近 3 個桶，按「帶我去」導航。
     太遠就按 **「好遠！」**：「這一按就是一筆『這裡需要桶』的資料，匿名、不用登入，而且會直接算進需求分數。」
   - **碰貼紙**：手機碰巡桶貼紙（或掃 QR）→ 跳出「汪！今日巡桶任務開始！」→ 拍照、選「垃圾桶滿了！」→ 送出 → 播扭蛋劇情、卡片收進圖鑑。
   - **多方佐證**：第二支手機回報同一個桶 → 地圖上這筆升級成「多方佐證」。
   - **佔領**：滑到打卡頁下方的「佔領榜」：「巡滿 3 次就能佔領這個桶、幫它取名，名字會掛在地圖上；別人要在你佔領之後重新巡滿 3 次、而且你佔領滿 8 小時才搶得走。」
     舉審核例子：「柴柴的秘密基地」會通過，「蔣萬安的桶」「全聯福利中心」會被擋。
     > 台詞：遊戲化不是為了好玩，是為了讓同一個桶有人固定回來看——固定巡的人越多，桶況資料就越準。

3. **找回（30s）**：地圖打開 👻「已確認消失」圖層，點紫色的桶：「環保局清單移除於 2026-10-xx」。
   > 台詞：open data 沒有歷史版本，撤掉就消失了。我們從上線那天開始每天幫市府留紀錄。

4. **決策（60s）**：地圖打開 🔥「需求熱力」，點第一名的紅色格子（南港理想公園一帶），彈出分數組成：哪個捷運出口、幾個站牌、幾個袋箱、最近的清潔箱多遠、扣了哪些桶。
   回 `/candidates` 按匯出 CSV：「這張表可以直接附在環保局的『設置／拆除／遷移評估表』後面送會勘。」
   > 台詞：每一格都說得出為什麼，權重全部公開、可以調整。

5. **落地（15s）**：零硬體先跑 3 個月 → 用需求分數挑 20 個點復設 → 這 20 個點裝感測器驗證 → 擴大到全市。

---

**現場狀況備案**

- 網路不穩：先用筆電投影正式站；手機操作的部分改成口頭講加截圖。
- 佔領無法現場從零示範（3 次最快要 16 小時）。一定要現場看到「恭喜你佔領這個桶」的話，demo 前請 wildcat 暫時調低門檻。
- 「多快會滿」頁面是示意數字，不要拿來當實際數據講。
- 斷網時的離線備援：在自己筆電的本機環境跑 `php artisan migrate:fresh --seed`，約 30 秒重建全部資料（open data 都在 repo 內）。**只能在本機跑，絕對不要在正式站執行**，會清空資料庫。
