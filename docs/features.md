# 功能與 UI 動線

## 民眾地圖（Mobile-first 主畫面）

```
┌────────────────────────────────┐
│ ● CIVICSHIELD 全民災情回報地圖 EN│ ← 頂部品牌 + 語言切換
│ 💧淹水 🚧道路 ⚡停電 🏚️結構     │ ← 分類篩選 chips（可多選）
│ 🏠收容所 🌀雷達回波            │ ← 圖層開關 chips
│ 🔍 🌙                          │ ← 左上：地標搜尋 / 亮暗切換
│                                │
│        🗺  全螢幕情勢地圖      │ ← Leaflet，點位分色 + 聚合
│                                │
│  📡 NCDR 跑馬燈廣播            │
│  ⚠️ 立即回報災情              │ ← 底部主 CTA
│  EOC 戰情室 回報清單 透明度…   │ ← Footer
└────────────────────────────────┘
```

## 動線

### A. 訪客看情勢圖
1. 進首頁，瀏覽器自動詢問定位
2. 地圖依 viewport 向 `/api/map/reports` 抓點；低 zoom 看聚合數字、高 zoom 看個別點位
3. 點位分色對應圖例（淹水藍／道路橘／停電黃／結構紅），核實層級以透明度/白框區分

### B. 分類篩選與圖層
- 頂部 chips 可切換四類災情顯示（多選）；關掉某類即從地圖移除
- `🏠 收容所`（綠）與 `🌀 雷達回波`（半透明 ImageOverlay）為獨立圖層開關
- 淹水潛勢 WMTS 圖層僅在設定 `FLOOD_POTENTIAL_WMTS_URL` 時才出現 chip

### C. 訪客回報（未登入）
1. 點「立即回報災情」→ 觸發 `AuthOnboarding` 抽屜（底部彈出）
2. 顯示隱私權文案 + LINE / Google 登入按鈕（災時主入口預期是 LINE）
3. 登入成功 → 自動回首頁並開啟回報表單

### D. 已登入使用者回報
1. 點「立即回報災情」→ 直接開啟 `ReportForm`
2. **災情分類**（必選，四鈕，配色對應圖例）：💧淹水 / 🚧道路中斷 / ⚡停電 / 🏚️結構受損
3. 選「淹水」時追加**目測水深**快選（腳踝/小腿/及膝/及腰/一層樓，選填）
4. 📸 照片（**選填**；災時拍照以自身安全為優先）
5. 📍 位置（小地圖，拖曳中心圖釘微調；支援照片 EXIF 定位）
6. 📝 補充說明（選填）
7. 送出 → **寫入即回應**（AI 審核 queue 後補）→ 顯示「📡 回報成功」→ 地圖重新抓點
   - 無照片 → 直接以 `unverified` 上圖（最低視覺層級），靠佐證升級
   - 有照片 → 照片經 AI 審核通過前不公開，但點位照常顯示

### E. 佐證自動升級
- 同一 150m 網格內、6 小時內、3 個不同帳號回報同類災情 → 該群點位自動升級「多方佐證」（實心）
- 官方核實（加白框徽章）由後台人工標記，民眾端無法觸發

### F. 地標搜尋 / 亮暗切換 / 多語系
- 地標搜尋（Nominatim OSM，`countrycodes: tw`）、地圖亮暗切換、中/EN 語言切換皆**無需登入**
- 地圖主題偏好存 `localStorage`（key: `civicshield_map_theme`，預設暗色）

## EOC 戰情室（`/dashboard`，公開唯讀大屏）

版面對應 mockup：

```
┌─ CIVICSHIELD  [MONITORING/TYPHOON]  NCDR 跑馬燈    03:40:12 ─┐
├─────────────┬──────────────────────────┬─────────────────────┤
│ CWA 即時    │                          │ 事件統計（近24H）    │
│ 27°C 時雨量 │      中央情勢地圖         │ ┌────┐┌────┐        │
│ 24H 雨量趨勢│    （bbox API + 行政區界）│ │積水││道路│        │
│ (Chart.js)  │                          │ └────┘└────┘        │
│ NCDR 燈號   │                          │ 物資/民力調度看板    │
│             │                          │ 沙包 340/500 ▓▓▓░   │
├─────────────┴──────────────────────────┴─────────────────────┤
│ ● CWA ● NCDR ● 雷達 ● DATA.TPE   今日回報 128 官方核實 1 Queue 0│ ← 真實健康指標
└──────────────────────────────────────────────────────────────┘
```

- **統計卡片**（spec §6.3）：各分類近 24h count + `+N 過去1H`；排除內容退件，**不排除** unverified
- **頂部徽章**：涵蓋台北市之颱風警戒存在時切為紅色 `TYPHOON-EMERGENCY`，否則 `MONITORING`
- **footer 真實健康指標**（spec §2 設計修正）：各外部源狀態燈（綠=正常/黃=延遲/紅=中斷）、
  最後成功時間、queue 深度、今日回報數、官方核實數。**不做 mockup 上的假 mesh 數據**
- 外部源中斷時對應面板顯示「資料更新中斷 + 最後更新時間」而非壞版面（驗收 §1-1）
- 更新：`wire:poll.10s`（統計/跑馬燈/健康）；整頁 10 分鐘 meta refresh 兜底

## 後台（Filament `/admin`）

- **災情回報**：分類/狀態/核實層級篩選；核准（公開照片）、標記官方核實、標記已排除、退件、批次核准/封鎖
- **收容所**：災時開設狀態 `is_open` 以 ToggleColumn 即時切換（自動 busts 民眾地圖 `map.shelters` 快取）
- **物資看板**：`current_qty` 以 TextInputColumn 快速編輯；現量不得超過上限
- **聯絡訊息**：沿用 ratdar（未讀標記 + Gmail API 一鍵回覆）
